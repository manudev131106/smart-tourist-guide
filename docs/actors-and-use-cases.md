# Actors and Use Cases

## Actors

### 1. Tourist / User
The main user of the Smart Tourist Guide System.

### 2. Administrator
Manages destinations, content, users, and reviews.

### 3. AI / LLM Recommendation Engine
Provides recommendations and assists in itinerary generation and optimization.

### 4. Map / Location API
Provides maps, locations, routes, and directions.

### 5. Weather API
Provides weather forecast information.

### 6. Payment Gateway
Processes payments for bookings.

### 7. Scheduler
Triggers scheduled tasks such as sending trip reminder emails.
